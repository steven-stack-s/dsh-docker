# 03 · 升级与维护

> [English](../en/03-upgrade-maintenance.md) | [简体中文](03-升级与维护.md)

## 1. 升级 DSH（无需重建镜像）

镜像构建时已把 dsh+pnpm 预装到 seed（`/opt/dsh-seed`），首次启动复制到 `/opt/dsh`。升级 = 容器内 npm 覆盖 `/opt/dsh`：

```bash
docker exec dsh npm install -g @deepseek-ai/dsh@<新版本>
docker restart dsh
```

> ⚠ **升级前先备份**（见 §5 备份）：跨大版本升级可能包含**不可回读**的数据格式变更 —— 例如
> `0.1.2-rc.1 → 0.1.5-rc.1` 会把会话数据升级到 V3，迁移后**旧版本无法再读取**这些会话（原文件保留，
> 但新版格式不被旧版识别）。因此回退 dsh 版本时必须连同 `dsh/` 数据目录一起回滚。
>
> 想留一个可回退的落点，用 `docker exec dsh rescue dsh-upgrade <版本>`：它会先把当前版本记为 last-good。

查看当前版本：

```bash
docker exec dsh dsh --version
```

> 重建镜像的场景：基础环境变化（Node 大版本 / 系统依赖），或想更新镜像内 seed 的 dsh 基础版本：
> `docker build --build-arg DSH_VERSION=<版本> --build-arg APT_MIRROR=mirrors.aliyun.com -t <你的仓库>/dsh-docker:<版本> .` 并更新 `.env` 的 `DSH_IMAGE`。

## 2. 安装 / 卸载插件

```bash
docker exec dsh dsh plugin --profile web add <包名>
docker exec dsh dsh plugin --profile web remove <包名>
docker restart dsh
```

插件与数据写入 `/data/dsh` 卷，容器重建/重启不丢。

> ⚠ 插件变更（尤其 update/install）是启动失败的最高频来源。建议用《[06 · 救援模式](06-救援模式.md)》的封装命令装插件（变更前自动快照）；若装坏导致起不来，entrypoint 会自动回退。

## 3. 更换 API 密钥

```bash
# 编辑 .env，修改 DEEPSEEK_API_KEY 后：
docker compose up -d
```

## 4. 查看状态与日志

```bash
docker ps | grep dsh              # 容器状态（healthy / starting / unhealthy）
docker logs dsh --tail 100        # 日志
docker stats dsh                  # 资源占用
```

## 5. 备份

**备份整个部署目录即可**（程序 + 数据 + 配置全在里面）：

```bash
cd <部署目录>        # 含 docker-compose.yml 的目录
tar czf dsh-backup-$(date +%Y%m%d).tar.gz dsh programs workspace .env
```

恢复：把备份解压回原目录，`docker compose up -d` 即可。

> 数据中最重要的是 `dsh/`（DSH_HOME：会话、配置、插件、凭据、Hindsight 记忆库）。
> `workspace/` 是 agent 工作区，按需备份。

## 6. 更新镜像（基础环境变化时）

```bash
docker compose pull        # 拉取新版本 ghcr.io 镜像
docker compose up -d       # 重建容器
```

## 7. 常见维护命令速查

| 操作 | 命令 |
|---|---|
| 查看版本 | `docker exec dsh dsh --version` |
| 升级 DSH | `docker exec dsh npm install -g @deepseek-ai/dsh@<版本> && docker restart dsh` |
| 装插件 | `docker exec dsh dsh plugin --profile web add <包名> && docker restart dsh` |
| 换密钥 | 改 .env → `docker compose up -d` |
| 重启 | `docker restart dsh` |
| 备份 | `tar czf backup.tar.gz dsh programs workspace .env` |
